# Trinity English School — responsive redesign

Five-page standalone HTML5/CSS3/JavaScript redesign for Trinity English School. The homepage uses the full-screen video hero supplied from the `01-theme` reference, adapted with Trinity-specific content and links.

## Pages

- Home
- School Hours
- Gallery
- Academy
- Contact Us

## Run locally

```powershell
npm start
```

Open `http://127.0.0.1:4173`. The pages can also be opened directly through their `index.html` files.

## Notes

All school text, photographs, address, telephone number and schedules come from the public Trinity English School website. The contact form has browser validation and a local confirmation state; connect it to a server/email provider before production message delivery.
